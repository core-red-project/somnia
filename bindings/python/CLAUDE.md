# Python Bindings (`somnia-audio`)

## Purpose
Python bindings for the Somnia procedural audio core via ctypes and the C ABI.

## Tooling
- Package manager: `uv`
- Build backend: `hatchling`
- Style & Docstrings: Google-style docstrings with PyDoc (`@public`, `@internal`)
- Testing: `pytest`

## Testing
`pytest tests/` (or `uv run pytest`)
