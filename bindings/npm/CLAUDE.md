# TypeScript / NPM Package (`@sxnnyside/somnia`)

## Purpose
TypeScript and Web Audio API bindings for the Somnia procedural audio core.

## Tooling
- Runtime & Package manager: `bun`
- Formatter & Linter: `biome`
- Type checker: `tsc`
- Doc comments: TSDoc (`@public`, `@internal`, `@param`, `@returns`, `@example`)
- Testing: `bun test`

## Testing
`bun test`
